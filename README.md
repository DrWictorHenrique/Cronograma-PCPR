# Cronograma Delegado

Planner de 12 meses (26/10/2026 a 24/10/2027) para Delegado de Polícia Civil, núcleo comum FGV/Cebraspe.

- `index.html`: cronograma, desempenho, materiais e configurações (mesmo motor do Cronograma-PCPR, dados em `deleg-v1`).
- `banco.js`: teoria e questões inéditas, entregues por rodadas. Para atualizar, substitua só este arquivo.

Publicação: GitHub Pages, branch `main`, pasta raiz.
