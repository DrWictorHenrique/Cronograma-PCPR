# Cronograma Delegado

Planner de 12 meses (26/10/2026 a 24/10/2027) para Delegado de Polícia Civil, núcleo comum FGV/Cebraspe.

- `index.html`: cronograma, teoria, questões, caderno de erros, desempenho, materiais e configurações.
- `drive.js`: login Google, progresso em `progresso.json`, leitor de PDF, caderno de erros e ajuste automático.
- `banco.js`: primeira rodada de teoria e questões inéditas. As rodadas seguintes chegam em `banco.json`, no Drive.

Dados (ficam só no Google Drive do usuário, pasta `Delegado-DB`; nunca neste repositório):
`indice.json` (tópico → PDF e página), `banco.json` (teoria e questões), `progresso.json` (criado pelo planner) e os PDFs.

Publicação: GitHub Pages, branch `main`, pasta raiz. No Google Cloud, a origem autorizada do Client ID é `https://drwictorhenrique.github.io`.
